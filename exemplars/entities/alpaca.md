# Alpaca

Alpaca is a language model created by finetuning Llama-7B on examples generated by
the much larger text-davinci-003 model (Taori et al., 2023). In the book it is the
example of a student **finetuned from an existing pre-trained model**, as distinct
from training a student from scratch (the DistilBERT route). See
[[model-distillation]] for the general method (AIE p.395).

## Key figures
- Student: Llama-7B (7 billion parameters)
- Teacher: text-davinci-003 (175 billion parameters)
- Alpaca is 4% the size of its teacher while behaving similarly (AIE p.395)
