# AlphaGeometry

AlphaGeometry is DeepMind's Olympiad-level geometry model, trained using template-generated synthetic math examples (Trinh et al., 2024) (AIE p.384). It illustrates rule-based data synthesis applied to formal-grammar domains like math equations.

## Key figures
- Trained using 100 million synthetic examples (AIE p.384)
