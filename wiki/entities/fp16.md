# FP16

FP16 (half precision) is a floating-point format using 16 bits (2 bytes) to represent a value, following the IEEE 754 standard (AIE p.325). Loading a model in FP16 when it was released in BF16 can cause significant quality degradation: Llama 2 shipped with BF16 weights, and teams that loaded it in FP16 instead found the model's quality much worse than advertised (AIE p.328). Values out of bound in FP16 are rounded to infinity (AIE p.327).

## Key figures
- 16 bits / 2 bytes per value (AIE p.325)
- 1234.56789 converts to 1235.0 in FP16, a 0.035% value change (AIE p.327)
- 123456.789 is out of bound in FP16 and rounds to infinity (AIE p.327)
