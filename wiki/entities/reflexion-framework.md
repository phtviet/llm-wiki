# Reflexion

Reflexion (Shinn et al., 2023) is an agent framework that separates reflection into two modules: an evaluator that scores the outcome, and a self-reflection module that analyzes what went wrong. The authors call a plan a 'trajectory'; at each step, after evaluation and self-reflection, the agent proposes a new trajectory (AIE p.294).
