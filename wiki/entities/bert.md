# BERT

BERT (bidirectional encoder representations from transformers) is a well-known [[masked-language-model]], trained to predict missing tokens using context from both directions (Devlin et al., 2018) (AIE p.4). It is the book's canonical example of a masked language model, contrasted with autoregressive models used for text generation (AIE p.4).
