# ANN-Benchmarks

ANN-Benchmarks is a website that compares different approximate nearest neighbor (ANN) algorithms across multiple datasets, accounting for the trade-off between indexing and querying. It reports four main metrics: recall (fraction of true nearest neighbors found), queries per second (QPS), build time (time to build the index), and index size (storage required) (AIE p.266).
