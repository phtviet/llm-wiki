# Promptbreeder

Promptbreeder is DeepMind's AI-powered prompt optimization tool (Fernando et al., 2023). It leverages an evolutionary strategy to selectively 'breed' prompts: starting from an initial prompt, it uses an AI model to generate mutations of that prompt, guided by a set of mutator prompts. It then generates further mutations from the most promising mutation, and repeats this process until it finds a prompt satisfying the user's criteria (AIE p.230).
