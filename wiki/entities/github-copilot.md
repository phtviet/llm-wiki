# GitHub Copilot

GitHub Copilot is a code completion tool and one of the earliest successes of foundation models in production (AIE p.20). It is cited as a landmark example of a foundation-model-powered coding assistant reaching rapid commercial success (AIE p.20).

## Key figures
- Annual recurring revenue crossed $100 million only two years after launch (AIE p.20)
