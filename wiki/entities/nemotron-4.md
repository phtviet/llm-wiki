# Nemotron-4

Nemotron-4 is NVIDIA's model family illustrating that training with synthetic data is not always model distillation. NVIDIA researchers first pre-trained a 340B-parameter base model, then finetuned it using instruction and preference data generated by Mixtral-8x7B-Instruct-v0.1, a 56-billion-parameter mixture-of-experts model (Jiang et al., 2024). The resulting student, Nemotron-4-340B-Instruct, outperformed its teacher on a variety of tasks (NVIDIA, 2024), so the relationship is not distillation in the strict sense: distillation implies the teacher's performance is the student's gold standard, and here the student surpassed the teacher (AIE p.396).

Comparing the parameter count of a mixture-of-experts model like Mixtral to that of a dense model like Nemotron-4 is not a fair comparison, but the point that the teacher (Mixtral) is smaller than the student (Nemotron-4) still holds (AIE p.396).

## Key figures
- Base model pre-trained at 340B parameters (AIE p.396)
- Finetuned using instruction/preference data from Mixtral-8x7B-Instruct-v0.1, a 56-billion-parameter mixture-of-experts model (AIE p.396)
- Nemotron-4-340B-Instruct outperformed its teacher model on a variety of tasks (AIE p.396)
