# Public Dataset Resources

A set of resources the book recommends for finding publicly available datasets before investing in creating new data. It stresses that available data should never be fully trusted -- it needs thorough inspection and validation, and a dataset's license should always be checked, since even a dataset licensed for commercial use may partly derive from a source that isn't (AIE p.379).

The resources named are: Hugging Face and Kaggle (each hosting hundreds of thousands of datasets), Google Dataset Search, government portals Data.gov and data.gov.in, the University of Michigan's ICPSR, UC Irvine's Machine Learning Repository and OpenML, the Open Data Network, cloud providers' open-data collections (notably AWS's Open Data), ML framework bundled datasets such as TensorFlow datasets, evaluation-harness-hosted benchmark datasets, and the Stanford Large Network Dataset Collection for graph data (AIE p.379).

## Key figures
- Hugging Face and Kaggle each host hundreds of thousands of datasets (AIE p.379)
- Data.gov hosts hundreds of thousands of datasets; data.gov.in hosts tens of thousands (AIE p.379)
- University of Michigan's ICPSR has data from tens of thousands of social studies (AIE p.379)
- Eleuther AI's lm-evaluation-harness hosts 400+ benchmark datasets, averaging 2,000+ examples per dataset (AIE p.379)
