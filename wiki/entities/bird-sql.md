# BIRD-SQL

BIRD-SQL (Li et al., 2023) is a text-to-SQL benchmark that evaluates not only a generated query's execution accuracy but also its efficiency, measured by comparing the runtime of the generated query against the runtime of the ground-truth SQL query (AIE p.162).

## Key figures
None. The section describes BIRD-SQL's evaluation method (execution accuracy plus runtime comparison) without a specific numeric score.
