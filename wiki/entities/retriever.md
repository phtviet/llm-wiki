# Retriever

The retriever is the component of a [[rag-architecture]] responsible for retrieving information relevant to a query from external memory sources. It has two main functions: indexing, which processes data so it can be quickly retrieved later, and querying, which sends a query to retrieve data relevant to it. How data is indexed depends on how it will later be retrieved. The success of a RAG system depends on the quality of its retriever (AIE p.256).
