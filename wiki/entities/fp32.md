# FP32

FP32 (single precision) is a floating-point format that uses 32 bits (4 bytes) to represent a value, following the IEEE 754 standard (AIE p.325). It is still the default format for NumPy and pandas, but is rarely used in neural networks today because of its memory footprint compared to FP16 (AIE p.326).

## Key figures
- 32 bits / 4 bytes per value (AIE p.325)
- Example conversions to lower precision: 0.0123456789 -> 0.0123443603515625 (FP16), 0.0123291 (BF16), 0.0123443603515625 (TF32) (AIE p.327)

## Related
