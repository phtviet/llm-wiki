# Cappy

Cappy is a reward model developed by Google (2023). Given a (prompt, response) pair it produces a score between 0 and 1 indicating how correct the response is. It is a lightweight scorer, much smaller than general-purpose foundation models (AIE p.147).

## Key figures
- 360 million parameters (AIE p.147)
- Outputs a correctness score between 0 and 1 (AIE p.147)
