# Yi model family

The Yi model family's creators found that a small set of carefully crafted instructions outperforms a much larger set of noisy instructions when finetuning (Young et al., 2024). The book cites this finding as supporting evidence, alongside LIMA, that data quality matters more than [[data-quantity]] for finetuning (AIE p.368).

## Key figures
- 10K carefully crafted instructions found superior to hundreds of thousands of noisy instructions (AIE p.368)
