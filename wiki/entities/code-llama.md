# Code Llama

Code Llama is a family of models made from the base model [[llama-2]] using different finetuning techniques, including instruction finetuning (supervised finetuning) and [[long-context-finetuning]] (Rozière et al., 2024) (AIE p.310).

## Key figures
- Long-context finetuning increased its maximum [[context-length]] from 4,096 tokens to 16,384 tokens, to accommodate longer code files (AIE p.310)
