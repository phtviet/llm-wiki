# AIE -- AI Engineering (Chip Huyen, O'Reilly, 2024)

Immutable source. Citation label **AIE**. Cite as (AIE p.NNN) using printed book pages.
Covered by this ingest: Chapter 1, 'Foundation Model Use Cases', book pp.16-20. Surveys how industry categorizes generative AI use cases (AWS, O'Reilly, Deloitte, Gartner), presents the Eloundou et al. (2023) study of occupational exposure to AI, and proposes an eight-category taxonomy of consumer and enterprise use cases (coding, image/video production, writing, education, conversational bots, information aggregation, data organization, workflow automation) drawn from 50 company interviews, 100+ case studies, and 205 open source GitHub repositories. Also discusses enterprises' preference for internal-facing and close-ended applications over external-facing, open-ended ones.
