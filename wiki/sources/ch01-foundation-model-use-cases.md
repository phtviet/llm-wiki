# AIE — AI Engineering (Chip Huyen, O'Reilly, 2024)

Immutable source. Citation label **AIE**. Cite as (AIE p.NNN) using printed book pages.
Covered by this ingest: Chapter 1, "Foundation Model Use Cases" section, book pp.16-19.

This section surveys how different organizations (AWS, O'Reilly, Deloitte, Gartner) categorize
generative AI use cases, summarizes Eloundou et al. (2023)'s research on occupational exposure
to AI, and presents the author's own eight-category breakdown of common generative AI use
cases (coding, image/video production, writing, education, conversational bots, information
aggregation, data organization, workflow automation) drawn from interviews with 50 companies,
over 100 case studies, and 205 open source GitHub applications. It also notes that enterprises
prefer lower-risk, internal-facing, and close-ended applications over external-facing,
open-ended ones.
