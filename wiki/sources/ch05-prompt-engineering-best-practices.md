# AIE — AI Engineering (Chip Huyen, O'Reilly, 2024)

Immutable source. Citation label **AIE**. Cite as (AIE p.NNN) using printed book pages.
Covered by this ingest: Chapter 5, 'Prompt Engineering Best Practices', book p.220.

This short section frames prompt engineering best practices as techniques distilled
from tutorials by model providers (OpenAI, Anthropic, Meta, Google) and from teams
that have deployed generative AI applications successfully. It notes that hacky,
model-specific tricks (e.g. writing 'Q:' instead of 'Questions:', or promising a
monetary tip) can become outdated as models improve, and that the following
techniques are meant to be general and durable across models. It points readers to
model providers' own prompt libraries and model-specific prompt engineering guides
for quirks not covered by general practice (AIE p.220).
