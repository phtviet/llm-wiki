# AIE — AI Engineering (Chip Huyen, O'Reilly, 2024)

Immutable source. Citation label **AIE**. Cite as (AIE p.NNN) using printed book pages.
Covered by this ingest: Chapter 10, 'Step 5. Add Agent Patterns', book pp.463-465.

This section describes extending a simple sequential AI application architecture with agentic patterns: loops that feed a generated response and newly retrieved context back into the same or a different model, and write actions (composing an email, placing an order, initializing a bank transfer) that let a system change its environment directly. It notes that added complexity increases capability but also introduces more failure modes and points of failure, motivating the next section's focus on observability.
