# Model Licenses

Foundation models are released under a wide variety of licenses -- many with their own bespoke terms rather than standard open source licenses like MIT, Apache 2.0, or GPL. Meta released Llama 2 under the Llama 2 Community License Agreement and Llama 3 under the Llama 3 Community License Agreement; Hugging Face released BigCode under the BigCode Open RAIL-M v1 license. Google's Gemma and Mistral-7B, by contrast, use the standard Apache 2.0 license (AIE p.181-182).

Key questions to ask of any model license: does it allow commercial use (Meta's first Llama model did not); does it impose restrictions on commercial use (Llama 2 and Llama 3 require a special license above 700 million monthly active users); and does it allow using the model's outputs to train or improve other models. This last question matters because synthetic data generated by existing models is an important data source, and one use of it is [[model-distillation]] -- teaching a smaller student to mimic a larger teacher. Mistral originally disallowed this use but later changed its license; the Llama licenses still do not allow it as of writing. Even where a license permits this, a model trained on another model's outputs can still violate that other model's terms of use, making data lineage important to track (AIE p.182).

Some use the term "restricted weight" for open source models with restricted licenses, though the book considers this ambiguous since all sensible licenses carry some restrictions (AIE p.182).
