# Data Flywheel

A data flywheel leverages data generated by a product's own users to continually improve that product, creating a compounding advantage: more usage produces more data, which improves the product, which drives more usage. Application-generated data is ideal for training because it is perfectly relevant and matches the true distribution of data a team cares about, something very hard to achieve from other data sources. User-generated data can take the form of user content, system-generated data from usage, or [[user-feedback]] (AIE p.377).
