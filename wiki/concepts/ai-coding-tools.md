# AI Coding Tools

Coding is the most popular use case for generative AI across multiple surveys, driven
both by AI's strength at coding tasks and by early AI engineers' own exposure to coding
challenges as coders themselves (AIE p.20). Beyond general-purpose coding assistants,
many tools specialize in narrower tasks: extracting structured data from web pages and
PDFs, converting English to code, generating code from a design or screenshot,
translating between programming languages, writing documentation, creating tests, and
generating commit messages (AIE p.20).

AI's usefulness varies by task. McKinsey researchers found AI helps developers be
twice as productive on documentation, and 25-50% more productive on code generation
and code refactoring, with minimal improvement on highly complex tasks. Developers of
AI coding tools have also observed that AI performs better on frontend than backend
development (AIE p.21). Predictions about the endpoint of this trend diverge sharply:
some expect AI to replace software engineers outright, while many software engineers
expect never to be replaced (AIE p.21).

## Key figures
- AI coding tools: gpt-engineer and screenshot-to-code each reached 50,000 GitHub stars within a year (AIE p.20)
- Developer productivity: ~2x for documentation, 25-50% more for code generation and code refactoring, minimal gain for highly complex tasks (AIE p.21)
