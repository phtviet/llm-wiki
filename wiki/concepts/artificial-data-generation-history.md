# Artificial Data Generation (History and AI-Era Expansion)

Artificially generated data has a long history in software engineering, originally used to generate fake data for testing purposes. Libraries like Faker and Chance generate data in simple formats such as names, addresses, phone numbers, and email addresses for testing -- for example, generating shipping addresses in different countries and formats to test a parsing program (AIE p.380).

With AI capable of generating data indistinguishable from human-generated data, it became possible to synthesize far more sophisticated data, such as doctor's notes, contracts, financial statements, product descriptions, images, and video commercials. This expansion makes data easier to generate and enables more synthetic data use cases (AIE p.380-381). Synthetic data promises to significantly reduce the pressure for human-generated data, but it does not completely replace it: mixing human- and AI-generated data often produces the best value (AIE p.381).
