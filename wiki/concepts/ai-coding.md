# AI Coding

Coding is the most popular use case across multiple generative AI surveys, driven both by AI's strength at coding tasks and by the fact that early AI engineers are themselves coders more exposed to coding challenges (AIE p.20). Beyond general-purpose coding assistance, many tools specialize in narrower tasks: extracting structured data from web pages and PDFs, converting English to code, generating code from a design or screenshot, translating between programming languages, writing documentation, creating tests, and generating commit messages (AIE p.20).

Whether AI can automate software engineering altogether is debated. NVIDIA CEO Jensen Huang has predicted AI will replace human software engineers, and AWS CEO Matt Garman has said most developers will stop coding in the near future, though he frames this as a change in the job rather than its end; many software engineers, by contrast, are convinced they will not be replaced (AIE p.21). Regardless of the replacement question, AI measurably increases developer productivity, and the effect varies sharply by task complexity and by frontend versus backend work (AIE p.21).

## Key figures
- McKinsey found AI can help developers be twice as productive for documentation, and 25-50% more productive for code generation and code refactoring, with minimal improvement on highly complex tasks (AIE p.21)
- Open source tools gpt-engineer and screenshot-to-code each reached 50,000 GitHub stars within a year of release (AIE p.20)
- Coding-startup funding: Magic raised $320 million and Anysphere raised $60 million, both in August 2024 (AIE p.20)
