# Plan Generation

Plan generation is the process of producing a plan -- a sequence of manageable actions -- for accomplishing a task; it is also called task decomposition (AIE p.284). The simplest implementation is [[prompt-engineering]]: the model is given a system prompt describing its available actions (with parameters) and a few examples mapping tasks to action sequences, then asked to produce a plan for the current task (AIE p.286).

Exact parameter values for each action are often impossible to predict in advance, since they depend on the outputs of earlier steps (e.g. a date returned by a `get_time()` call feeding into a later `fetch_top_products()` call), or on information the user never supplied. This means models must sometimes guess parameters, and the guesses can be wrong. Because both the action sequence and parameters are generated by AI models, they can be hallucinated, causing invalid function calls or valid calls with wrong parameters (AIE p.287).

Approaches to improve plan generation include: writing a better system prompt with more examples, giving clearer tool/parameter descriptions, simplifying the functions themselves (e.g. refactoring a complex function into two simpler ones), using a stronger model (stronger models are generally better at planning), and finetuning a model specifically for plan generation (AIE p.287-288).
