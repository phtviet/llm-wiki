# Intelligent Data Processing (IDP)

Intelligent data processing (IDP) is the use of AI to extract structured information
from unstructured data, which can then be used to organize and search that data.
Simple use cases include extracting information from credit cards, driver's licenses,
receipts, tickets, and contact information from email footers. More complex use cases
include extracting data from contracts, reports, and charts (AIE p.28).

## Key figures
- The IDP industry is estimated to reach $12.81 billion by 2030, growing 32.9% annually (AIE p.28)

## Examples
- Extracting fields from credit cards, driver's licenses, receipts, and tickets
- Extracting data from contracts, reports, and charts
