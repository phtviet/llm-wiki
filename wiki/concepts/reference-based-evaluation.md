# Reference-Based Evaluation

When a task cannot be automatically evaluated using [[functional-correctness]], one common approach is to evaluate AI outputs against reference data: examples in the format (input, reference responses), where reference responses are also called ground truths or canonical responses. An input can have multiple valid reference responses, such as multiple correct translations of a sentence. Metrics that require references are reference-based; metrics that don't are reference-free (AIE p.127).

Reference data is generated by humans or increasingly by AI. Using human-generated references treats human performance as the gold standard against which AI is measured. Human-generated reference data is expensive and slow to produce, which pushes many teams toward AI-generated reference data, still typically reviewed by humans but at far lower labor cost than generating it from scratch (AIE p.127).

Generated responses that are more similar to the reference responses are considered better. There are four ways to judge this similarity: an evaluator judgment call, exact match, lexical similarity, and semantic similarity. Exact match produces a binary score; lexical and semantic similarity produce scores on a sliding scale (AIE p.128). Despite the flexibility of AI-as-a-judge approaches, these hand-designed similarity measurements remain widely used in industry for their exact, reproducible nature (AIE p.128).

Beyond evaluation, similarity measurements against reference data underpin retrieval and search, ranking, clustering, anomaly detection, and [[data-deduplication]] (AIE p.128).
