# User Feedback

User feedback has always served software applications in two ways: evaluating an application's performance and informing its development. In AI applications, user feedback takes on an even greater role because it is proprietary data, and data is a competitive advantage (AIE p.474).

A well-designed user feedback system is necessary to build the [[data-flywheel]] described elsewhere in the book. Feedback can be used both to personalize models for individual users and to train future iterations of the models. As data becomes increasingly scarce, proprietary data grows more valuable, and a product that launches quickly and attracts users early can gather data to continually improve, making it harder for competitors to catch up (AIE p.474).

Because user feedback is user data, leveraging it requires the same cautions as leveraging any data: user privacy should be respected, and users have the right to know how their data is being used (AIE p.475).
