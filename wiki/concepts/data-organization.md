# Data Organization

Data organization is a foundation model use case addressing the growing volume of unstructured and semistructured data (photos, videos, logs, PDFs, contracts) that must be organized so it can be searched later (AIE p.27). Foundation models help by generating text descriptions of images and videos, matching text queries to matching visuals, and generating images when no existing one matches a query. Foundation models are also used for data analysis: writing programs to generate visualizations, identify outliers, and make predictions such as revenue forecasts (AIE p.27).

A related, more structured application is [[intelligent-data-processing]], which extracts structured information from unstructured data (AIE p.28).

## Key figures
None. The concept's only load-bearing figures belong to intelligent data processing specifically, per fact-placement.

## Examples
- Google Photos surfacing images matching search queries
- Google Image Search generating images when no match exists
