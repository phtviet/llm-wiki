# Agent

In this section, the agentic pattern is introduced alongside RAG as one of two dominant patterns for giving a model the context and capability it needs to solve a task: RAG retrieves relevant information from external data sources, while the agentic pattern allows a model to use external tools such as web search and news APIs to gather information (AIE p.253). Unlike RAG, which is chiefly used for context construction, agentic tool use can do much more: tools can help models address their shortcomings, expand their capabilities, and directly interact with the world, enabling automation of many aspects of life (AIE p.253).
