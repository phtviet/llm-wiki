# Workflow Automation

Workflow automation is the use of AI to carry out repetitive or time-consuming tasks that would otherwise require a human. For end users this covers everyday chores such as booking restaurants, requesting refunds, planning trips, and filling out forms. For enterprises it covers tasks such as lead management, invoicing, reimbursements, managing customer requests, and data entry (AIE p.28).

Many automation tasks require access to external tools: a restaurant-booking application, for instance, may need to search the web for a phone number, place a call, and add an entry to a calendar. AIs that can plan and use such tools are called [[ai-agents]] (AIE p.28).

One notable use case within workflow automation is using AI models to synthesize data that is then used to improve the models themselves, optionally looping in humans to refine the generated labels (AIE p.28).

## Examples
