# Vocabulary

A model's vocabulary is the set of all tokens it can work with (AIE p.3). A small number of distinct tokens can be combined to construct a very large number of distinct words, much as a small alphabet can construct many words (AIE p.3). Vocabulary size is decided by model developers as part of choosing a tokenization method (AIE p.3).

## Key figures
- Mixtral 8x7B has a vocabulary size of 32,000 tokens (AIE p.3)
- GPT-4 has a vocabulary size of 100,256 tokens (AIE p.3)
